# Contexte - Dominos VR (aframe-dominoes)

- **Quoi** : jeu de dominos multijoueur en réalité virtuelle dans le navigateur (casque, ordinateur, mobile), 2 à 4 joueurs, chat vocal spatialisé, bots, règles arbitrées par le serveur.
- **Pour qui** : des amis qui veulent jouer ensemble à distance. Logiciel libre, licence MIT, dépôt public.
- **Stack** : A-Frame, Node.js, WebSocket (`ws`), WebRTC, Docker sur Coolify.
- **État au 2026-11-01** : en ligne sur https://dominos.tafrap.fr, v1.3.0. Relais TURN absent, retours de test à consigner, 7 PR Renovate ouvertes, rattachement à GIGA Games en attente (DEC-001).
